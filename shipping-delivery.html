Shipping & Delivery Information

Welcome! Here's how we deliver our courses, course materials, and freelance services to you.

Everything is delivered digitally to ensure you get instant access and flexible collaboration on your projects.

Live Courses via Google Meet

How it works:

  • Live classes are conducted through Google Meet (video conferencing platform)
  • Schedule and meeting links will be shared via email before the course starts
  • You can join from any device with an internet connection (computer, tablet, smartphone)
  • Interactive Q&A sessions during live classes
  • Networking opportunities with other learners

What you need:

  • A stable internet connection
  • A device with a camera and microphone (optional but recommended)
  • Google Meet installed or access via web browser

Course Recordings via Email

How it works:

  • All live classes are recorded for your convenience
  • Recording links will be sent to your registered email address
  • Access recordings anytime, anywhere at your own pace
  • Watch and re-watch content as many times as you need
  • Download options available where permitted

Delivery timeline:

  • Recordings are typically shared within 24 hours of the live class
  • Check your email (including spam folder) for recording links
  • All recordings remain accessible throughout your course duration

Projects via GitHub

How it works:

  • All course projects and source code are shared via GitHub repositories
  • GitHub links will be provided in course materials and via email
  • Access project files, documentation, and starter code
  • Submit your project solutions to GitHub repositories
  • Get feedback on your code through GitHub issues and pull requests

Benefits:

  • Version control and collaboration features
  • Build your GitHub portfolio while learning
  • Access to complete project repositories
  • Learn industry-standard development practices

Freelance Development Services

How it works:

  • Custom web development, mobile apps, and software solutions tailored to your needs
  • Project discussion and requirements gathering via email or video call
  • Regular updates and progress reports shared through email or GitHub
  • Source code and deliverables shared via GitHub repositories or direct file sharing
  • Post-delivery support and maintenance options available

Deliverables include:

  • Complete, production-ready source code
  • Documentation and deployment guides
  • GitHub repositories for version control and collaboration
  • Testing reports and quality assurance documentation
  • Training or handover sessions if needed

Communication channels:

  • Email for project updates and file sharing
  • Video calls via Google Meet for discussions
  • GitHub for code collaboration and issue tracking
  • Dedicated support for the project timeline

Complete Delivery Process - Courses

Step 1: Course Enrollment

You receive a confirmation email with your login credentials and course details.

Step 2: Pre-Course Setup

Google Meet links and GitHub repository access details are shared 24 hours before the course begins.

Step 3: Live Classes Begin

Join live classes on Google Meet as per the schedule provided. Interact with instructors and peers in real-time.

Step 4: Recording Access

Within 24 hours of each class, recording links are sent to your email for lifetime access.

Step 5: Project Collaboration

Access project repositories on GitHub. Work on assignments and submit solutions for review.

Step 6: Continuous Support

Get help via email, GitHub discussions, and community forums throughout your course duration.

Freelance Project Delivery Process

Step 1: Initial Consultation

Discuss your project requirements, timeline, and budget via email or video call on Google Meet.

Step 2: Proposal & Agreement

Receive a detailed project proposal with scope, deliverables, timeline, and pricing. Agreement finalized.

Step 3: Project Kickoff

Project begins with technical setup. Regular updates and progress reports shared via email.

Step 4: Development & Collaboration

Active development with code shared on GitHub. You can track progress in real-time through the repository.

Step 5: Testing & Review

Project tested thoroughly. Testing reports and demos provided. Feedback incorporated and adjustments made.

Step 6: Delivery & Handover

Final deliverables including source code, documentation, and deployment guide shared. Training or handover sessions provided if needed.

Step 7: Post-Delivery Support

Maintenance and support services available. Bug fixes and minor updates included in agreed support period.

📌 Important to Know

All course materials are delivered instantly upon enrollment. Freelance projects are delivered according to the agreed timeline and scope. Make sure to check your email (including spam/promotions folder) for important course information and links. Your course access depends on your login credentials - keep them secure!
